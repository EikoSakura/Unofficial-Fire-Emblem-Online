# Fire Emblem Online for Foundry VTT (Unofficial)

A game system for playing the Fire Emblem Online tabletop rules in [Foundry Virtual Tabletop](https://foundryvtt.com/).

It comes with the rules as a journal, compendiums of classes, weapons, items, skills, Combat Arts and
Battalions, a character creator, unit sheets and a battle HUD for the map.

Requires Foundry VTT version 14.

## Installing

Use this manifest URL:

```
https://github.com/EikoSakura/Unofficial-Fire-Emblem-Online/releases/latest/download/system.json
```

**Foundry VTT:** on the setup screen open *Game Systems*, choose *Install System*, paste the manifest URL into
the *Manifest URL* box at the bottom and choose *Install*.

**The Forge:** open your game's setup screen the same way (*Game Systems*, *Install System*), paste the
manifest URL into the *Manifest URL* box and choose *Install*. The system is added to your Forge account and
can then be picked when you create a world.

## Updating

New versions are published as releases of this repository. Foundry and The Forge pick them up through the
manifest URL above, so *Update* on the *Game Systems* screen is all that is needed.
